3. Output

Generate an invoice or report for a project over a date range. ADB projects produce a rolling day-rate report. QBCC projects produce an hourly or flat-rate invoice.

Select a project and date range to generate the appropriate output:

  • ADB projects → Rolling accrual report (hours roll across days, billed in day fractions)
  • QBCC projects → Hourly or flat-rate invoice
  • AMEB projects → Manual timetable entry, generates invoice
